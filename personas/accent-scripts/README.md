## Conventions
- **Solo scripts:** one voice; `[thick exaggerated Japanese accent]` re-declared each
  paragraph; split on paragraph breaks for the ~3000-char render cap.
- **Two-handers:** names stripped, **strict A/B alternation** (V1 = Zane, V2 = Shane);
  assign voices per turn in Studio Dialogue mode. In `shane-zane-japan-ep.txt` the
  hosts speak in **normal voice**, dropping into the accent only for marked bits.
- Generate on **Eleven v3, Creative stability**. Tags are probabilistic — listen-pass
  and re-roll bad lines.

## Content note
The accent is a comedic voice device used on absurd / incongruous premises and
self-aware "doing the bit" beats. Avoid premises whose joke *is* a demeaning
competence stereotype tied to real tragedy (e.g. pilots crashing) — see session
history for the line that was held.
